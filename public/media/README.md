# Démo finale (acte 5)

Déposer ici la vidéo de l'application réelle sous le nom **`demo.mp4`**
(H.264, 16:9, idéalement 1920×1080, sans son ou son coupé).

- Si le fichier est présent, il est joué à l'étape « L'application » de l'acte 5.
- S'il est absent, une simulation animée (mail → lecture → workflow) le remplace.

Le chemin est configurable dans `src/content/content.json` → `acts[4].video`.
